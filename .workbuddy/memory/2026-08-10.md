## 平票重投无法选择 Bug（22:07）

- **根因**：上一轮修复（loadTheme 不再清空 selected）导致**第一轮提交后 selected 残留 {A,C}**；进入重投轮未清空 → `selected.size=2 ≥ vacancy=1` 被前端 toggleSel 拦截

- 验证：前端构建通过

## 000登录后白屏（22:27）
- **症状**：000 登录后什么也加载不出来
- **排查**：后端全部接口正常（theme/list 返回2主题）、前端编译正常、路由守卫正常 → 是运行时 JS 错误
- **根因**：ThemeEdit.vue 我上轮加的 WS 订阅写错：`const wsUnsub = ref(null)` 却在 onMounted 里 `wsUnsub = wsClient.subscribe(...)` 给 **const 重新赋值** → 运行时 TypeError → onMounted 抛错 → 页面白屏（编译期不报，构建照样通过，所以之前验证都没发现）

- **教训**：ref 赋值必须用 .value；Vue 组件里订阅函数用普通 let 变量更安全
